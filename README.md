# おこづかいちょう（Okozukai）

子ども（特に幼児）のお小遣いを、**スマホ1台で**かんたんに管理するアプリです。
ビルド不要・ログイン不要・サーバー不要。`index.html` を開くだけで動きます。
公開URL：https://nasuuuuun.github.io/Okozukai/

## 考え方：「アプリの残高＝自分のお金」

- 残高はいつも大きな1つの数字で表示（＝「あなたのお金」）。**通貨はシンガポールドル（$）**。
- お金を使ったら、その場で残高が減る。減るときにコインのアニメ＋効果音が出て、
  「自分のお金が減った」実感を後押しします。
- アプリの残高を“正”として扱うため、現金のやり取りや立替の精算といった作業は不要です。

## 画面と使い方

### 子どもの画面（メイン）
- 大きな残高（$）と、おさいふ👛のイラスト。
- 「**つかう**」→ 金額を入力（数字は**ドル**、`．`を押すと**セント**）→ カテゴリ（おかし等）を選ぶ
  → **けってい**。残高がアニメ＋音で減ります。
- お小遣いの予定日が来ると、🎁 **「おこづかいを もらう」ボタン**が出ます。押すとお祝い演出つきで
  設定金額が加算されます（**自動では加算しません**。「もらう」体験を残すため）。

### 設定（保護者用） … 右上 ⚙️
- **お小遣いを足す**：臨時のお小遣い（お年玉・ごほうび など）を残高に追加。
- **おこづかいの予定（もらう日）**：毎週／毎月・曜日／日・金額を設定。予定日が来ると
  メイン画面に「もらう」ボタンが出ます。（テスト用に「お小遣い日が来た状態にする」ボタンあり）
- **名前**：お子さんの名前。
- **履歴の訂正**：誤入力の削除。
- **バックアップ**：JSONで書き出し／読み込み。

> 設定画面に入るときの計算ゲートは現在オフです（`js/app.js` の `GATE_ENABLED` で切替）。

## スマホでの使い方（推奨：ホーム画面に追加）

1. iPhoneの Safari で公開URLを開く。
2. 共有ボタン →「ホーム画面に追加」。
3. ホーム画面の 👛 アイコンから起動。

これで、オフライン・PC不要・プライベートブラウズの影響なしで使えます。コードを更新したら、
オンラインでアプリを開き直すだけで最新になります（アイコンの入れ直しは不要）。

## データの保存とバックアップ

- データはこの端末のブラウザ内（localStorage）に保存されます。**サーバーには送られません。**
- ブラウザのデータ削除や機種変更で消えるため、**ときどき「書き出し」でバックアップ**してください。

## ファイル構成

```
Okozukai/
├─ index.html          # 画面のマークアップ
├─ css/styles.css      # スマホ優先のスタイル
├─ js/
│  ├─ sound.js         # WebAudioで効果音を生成
│  ├─ storage.js       # localStorageの保存・読込・バックアップ
│  ├─ logic.js         # 残高の計算・おこづかいの予定/受け取り・カテゴリ
│  └─ app.js           # 画面描画・操作・アニメ
├─ manifest.json       # PWA設定（ホーム画面に追加）
├─ icon.svg            # アプリアイコン（👛）
└─ sw.js               # オフライン用サービスワーカー（http/https時のみ）
```

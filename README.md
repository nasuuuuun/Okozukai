# おこづかいちょう（Okozukai）

子ども（特に幼児）のお小遣いを、**スマホ1台で**かんたんに管理するアプリです。
ビルド不要・ログイン不要・サーバー不要。`index.html` を開くだけで動きます。

## このアプリが解決すること

- 親がカードで**立て替え**た分の現金回収が追いつかず、**残額が分からなくなる**問題。
- 4歳の子が「立替」という概念を理解できず、**お金を使った実感が持てない**問題。

### 考え方：「アプリの残高＝唯一の正解」

1. 残高はいつも大きな1つの数字で表示（＝「あなたのお金」）。
2. **支払い方法に関係なく、使ったらその場で残高が減る。** 親がカードで立て替えても、
   タップすれば残高が即減り、子に「自分のお金が減った」実感が出ます（減るときにアニメ＋音）。
3. **現金の都度回収はやめます。** アプリが「親への立替残（子が実質親に返す現金）」を集計するので、
   親は都合のいいキリのいい金額でまとめて回収するだけ。お釣り問題が消えます。

## 使い方

### 開く / インストール
- そのまま `index.html` をブラウザで開いても動きます。
- スマホで使うときは、簡易サーバー経由で開いて「ホーム画面に追加」すると全画面アプリになります。
  - 例（PCで配信し同じWi-Fiのスマホから開く）：このフォルダで
    `python -m http.server 8000` を実行 → スマホのブラウザで `http://<PCのIP>:8000/` を開く。

### 子どもの操作（メイン画面）
- 大きな残高が見える。
- 「**つかう**」→ 金額をテンキーで入力 → カテゴリ（おかし等）を選ぶ →
  「げんきん」か「カード（おうちのひと）」を選ぶ → **けってい**。
  - げんきん：残高が減るだけ。
  - カード：残高が減り、さらに「親への立替残」が増えます。

### 親の操作（⚙️ おとなメニュー）
かんたんな計算ゲート（例：3＋4＝？）を通ると開きます。
- **おこづかいを たす**：お年玉などの臨時収入を追加。
- **たてかえ トラッカー**：立替残を確認し、現金を回収したらその額を入力（残高は変わりません）。
- **じどう おこづかい**：毎週／毎月・曜日／日・金額を設定。アプリを開いた時に予定日を過ぎていれば自動付与。
- **なまえ**：お子さんの名前。
- **りれきの ていせい**：誤入力の削除。
- **バックアップ**：JSONで書き出し／読み込み。

## データの保存とバックアップ

- データはこの端末のブラウザ内（localStorage）に保存されます。**サーバーには送られません。**
- ブラウザのデータ削除や機種変更で消えるため、**ときどき「かきだし」でバックアップ**してください。
- 別の端末・ブラウザへ移すときは「かきだし」→ 移行先で「よみこみ」。

## ファイル構成

```
Okozukai/
├─ index.html          # 画面のマークアップ
├─ css/styles.css      # スマホ優先のスタイル
├─ js/
│  ├─ sound.js         # WebAudioで効果音を生成
│  ├─ storage.js       # localStorageの保存・読込・バックアップ
│  ├─ logic.js         # 残高/立替の計算・自動付与・カテゴリ
│  └─ app.js           # 画面描画・操作・アニメ
├─ manifest.json       # PWA設定（ホーム画面に追加）
├─ icon.svg            # アプリアイコン
└─ sw.js               # オフライン用サービスワーカー（http/https時のみ）
```
